# まいにちドリル（Phase 1：土台＋算数／Phase 2：国語）

家庭用の子ども向け毎日学習アプリです。仕様は [`docs/SPEC.md`](docs/SPEC.md) を参照してください。

- Next.js 15（App Router, TypeScript strict）＋ Tailwind CSS
- Cloudflare Workers（OpenNext の `@opennextjs/cloudflare`）＋ Cloudflare D1
- テストは Vitest
- PWA（manifest・アイコン・Service Worker。ホーム画面に追加できる）

国語は、親が設定画面で「国語の初期レベル」を決めた子どもだけメニューに入ります（算数 → 国語の順）。英語は Phase 3 で追加予定で、いまは「じゅんびちゅう」と表示しています。

## 1. セットアップ（ローカル）

必要なもの：Node.js 20 以上（22 推奨）

```bash
cd drill
```

```bash
npm install
```

```bash
npm run db:migrate:local
```

ローカルの D1（`.wrangler/state/` の SQLite）にテーブルが作られます。

### 開発サーバー

```bash
npm run dev
```

http://localhost:3000 を開きます。`next.config.ts` で `initOpenNextCloudflareForDev()` を呼んでいるので、`next dev` でもローカルの D1 を使えます。

### 本番に近い確認（Workers のランタイムで動かす）

```bash
npm run preview
```

`opennextjs-cloudflare build` でビルドしてから `wrangler` で起動します（http://localhost:8787）。

### テスト

```bash
npm test
```

型チェックは `npm run lint:types` です。

## 2. 動作確認の手順（一通りの流れ）

1. `/parent/signup` で家族アカウントを作成します（名前・メール・パスワード・4桁の PIN）。
2. 下のメニューの「設定」→「子どもを追加」。算数の時間と初期レベルを決めます。動作確認なら時間を **1分** にすると早く終わります。
3. 子どものカードで「端末登録コードを発行」。6桁のコードが10分間有効です。
4. 子どものスマホ（または別のブラウザ・シークレットウィンドウ）で `/` を開き、「こどもの たんまつに する」でコードを入力します。
5. 子どもの画面で「はじめる」を押し、問題を解きます。
   - 答えるとすぐに 〇× が出ます。間違えた問題は、目標時間に達したあと「まちがいなおし」として全部正解するまで出ます。
   - 時間は「操作している間」だけ進みます。60秒操作がない、または別アプリに切り替えると止まり、「つづける」ボタンが出ます。
6. 算数が終わると「きょうは たっせい！」と表示され、カレンダーのその日が ⭐ になります。
7. 親の画面に戻り、ホーム（ダッシュボード）でその子が「達成」になっていることを確認します。

### 子ども端末の制限の確認

- 子ども端末から `/parent` などを開くと、子どものホームに戻されます。
- 子ども端末では親としてログインできません。
- 親の操作（Server Action）は、すべてサーバー側で「親のログイン＋PIN」を確認しています。子ども端末のブラウザで同じリクエストを再送しても拒否されます。

## 3. Cloudflare へのデプロイ

### 初回だけ

1. Cloudflare にログインします。

   ```bash
   npx wrangler login
   ```

2. D1 データベースを作成します。

   ```bash
   npx wrangler d1 create mainichi-drill
   ```

   表示された `database_id` を、`wrangler.jsonc` の `d1_databases[0].database_id` に書き込みます。

3. 本番 D1 にマイグレーションを適用します。

   ```bash
   npm run db:migrate:remote
   ```

4. デプロイします。

   ```bash
   npm run deploy
   ```

   `https://mainichi-drill.<アカウント>.workers.dev` で公開されます。独自ドメインは Cloudflare のダッシュボードの「Workers & Pages → mainichi-drill → Settings → Domains & Routes」で設定します。

### 2回目以降

テーブルを変更したときは、`migrations/` に新しい SQL ファイルを追加します（例：`npx wrangler d1 migrations create DB 説明`）。そのあと次の2つを実行します。

```bash
npm run db:migrate:remote
```

```bash
npm run deploy
```

`wrangler.jsonc` を変えたときは `npm run cf-typegen` で型（`cloudflare-env.d.ts`）を作り直します。

## 4. 本番で必要な環境変数・バインディング

アプリ自体が読む秘密の環境変数（API キーなど）は **ありません**。必要なのは `wrangler.jsonc` のバインディングだけです。

| 名前 | 種類 | 内容 |
|---|---|---|
| `DB` | D1 バインディング | 学習データを保存するデータベース。`database_id` を本番の値にする |
| `ASSETS` | 静的ファイル | OpenNext が生成する `.open-next/assets`（設定済み） |
| `WORKER_SELF_REFERENCE` | サービスバインディング | OpenNext が使う自分自身への参照（設定済み。Worker 名と同じにする） |

任意の環境変数（`wrangler.jsonc` の `vars`、またはダッシュボードの「Settings → Variables」で設定）：

| 名前 | 内容 |
|---|---|
| `ALLOW_UNREVIEWED_CONTENT` | `1` にすると、親の確認前（`reviewed: false`）の教材も本番で選べるようになります。ふだんは設定しません。開発中（`npm run dev`）は常に選べます |

CI（GitHub Actions など）からデプロイする場合は、次の値を CI の秘密情報に登録します。

| 名前 | 内容 |
|---|---|
| `CLOUDFLARE_API_TOKEN` | 「Workers Scripts:Edit」「D1:Edit」の権限を持つ API トークン |
| `CLOUDFLARE_ACCOUNT_ID` | Cloudflare のアカウント ID |

## 6. 実装上の決めごと

### 認証

- **パスワード・PIN**：PBKDF2-SHA256（ソルトつき・10万回）でハッシュ化します。Workers の PBKDF2 は10万回が上限です。
- **トークン類**：親のログイントークン・端末トークン・端末登録コードは SHA-256 で保存します。Cookie は httpOnly・Secure・SameSite=Lax です。
- **PIN**：一度入力すると「最後の操作から15分」有効です。5回間違えると5分ロックします。
- **レート制限**：ログインは15分に10回、端末登録コードは10分に10回まで失敗できます。
- **2人目の親**：設定画面から仮パスワードで追加します。初回ログイン時に、パスワードの変更と PIN の設定を求めます。
- **子ども端末**：端末 Cookie の期限は約400日で、使うたびに延長します。親画面から解除すると、すぐに使えなくなります。

### 学習の流れ

- **出題と採点**：問題と答えはサーバーだけが持ち、端末には答えを送りません。採点もサーバーで行います。
- **時間の計測**：時間は端末で測り、回答時と15秒ごとに送ります。サーバーは「前回の報告からの実際の経過時間」を上限に切り詰めて記録します。
- **教科の終わり**：目標時間に達したら、今の問題を答え終えてから間違い直しに入ります。間違い直しの時間も学習時間に含めます。
- **当て推量**：初期値は1秒未満です（設定で変更できます）。進級判定には使いません。
- **1回の学習**：1日・1教科の学習です。成績は「1回目の回答」だけで計算し、間違い直し・当て推量・復習で混ぜた前レベルの問題は除きます。また、判定に使える回答が5問未満の回は判定に使いません。

### 進級と復習

- **進級**：今のレベルになってからの直近3回が、すべて正答率90%以上かつ平均解答時間が目標以内なら、次のレベルへ進みます。
- **復習**：直近2回が続けて70%未満なら、前のレベルの問題を3割混ぜます。レベルは自動では下げません。成績が戻れば自動で解除します。

### 日ごとの状態と月の判定

- 状態は記録から毎回計算します。
- 終わった月の結果は、画面を開いたときに保存します（締めのバッチは使いません）。
- 特別休みをさかのぼって変更したときは、終わった月の結果を計算し直します。支払い済みのチェックは残します。
- 子どもを登録した日（`start_date`）より前の日は判定しません。
- **連続日数**：「達成」「特別休み」「お休み券」の日はつながったまま、「未達成」の日で途切れます。表示する日数は、つながっている間の「達成した日」の数です。

### 分数・小数の答え

| レベル | 約分していない答え |
|---|---|
| M22（同じ分母） | 値が同じなら 〇（「やくぶん できるよ」と表示） |
| M23（約分） | 既約分数だけ 〇 |
| M23（通分） | 「2/3 = □/12」の分子を整数で答える |
| M24・M27・M28 | ×（「あと やくぶん！」と表示して間違い直しへ） |
| 小数 | 値が同じなら 〇（0.50 も 0.5 も正解） |

- 仮分数・帯分数のどちらでも答えられます。帯分数の分数部分は真分数にします。
- 答えが整数になる場合は、整数で答えます（2/1 は約分していない扱い）。

### 算数レベルの目標平均解答時間（初期値）

| レベル | 目標 | レベル | 目標 | レベル | 目標 |
|---|---|---|---|---|---|
| M01 | 4秒 | M11 | 3秒 | M21 | 20秒 |
| M02 | 4秒 | M12 | 4秒 | M22 | 12秒 |
| M03 | 5秒 | M13 | 7秒 | M23 | 15秒 |
| M04 | 5秒 | M14 | 10秒 | M24 | 30秒 |
| M05 | 6秒 | M15 | 15秒 | M25 | 20秒 |
| M06 | 8秒 | M16 | 30秒 | M26 | 25秒 |
| M07 | 12秒 | M17 | 15秒 | M27 | 20秒 |
| M08 | 15秒 | M18 | 25秒 | M28 | 25秒 |
| M09 | 3秒 | M19 | 30秒 | M29 | 30秒 |
| M10 | 3秒 | M20 | 15秒 | | |

秒数は `src/domain/math/levels.ts` で変更できます。

### PWA

- **manifest**：`app/manifest.ts` で作ります。
- **アイコン**：`public/icons/` にあり、元の SVG は `scripts/icon.svg` です。作り直すときは `node scripts/make-icons.cjs` を実行します（Playwright が必要）。
- **Service Worker**：`public/sw.js` です。本番でのみ登録します。
  - キャッシュするのは静的ファイルだけです。画面と API は常にネットから取得します（子どもの記録などの個人情報を端末にキャッシュしないため）。
  - オフラインのときは「つながっていません」のページを出します。

## 7. 国語（Phase 2）

### レベル

| コード | 内容 | 出題の形 |
|---|---|---|
| K01 | ひらがな（清音・濁音・半濁音・拗音） | 文字を見て、その文字で始まる絵を選ぶ／読み上げを聞いて文字を選ぶ |
| K02 | カタカナ | カタカナを見て読み（ひらがな）を選ぶ／読み上げを聞いて文字を選ぶ |
| K03〜K09 | （空き番号） | |
| K10〜K61 | 学年別漢字配当表 1,026字を、学年ごとに約20字ずつ | 例文の中の漢字の読みを選ぶ／読みに合う漢字を選ぶ |

- **漢字のレベル数**：1年は4レベル、2年は8レベル、3〜6年は10レベルずつです。学年の中は配当表の並び順（音読みの50音順）で区切ります。
- **聞き取りの問題**：日本語の読み上げの声がある端末でだけ出ます。ない端末では、見て選ぶ問題だけになります。
- **ふりがな**：子どもの「漢字の表示」設定（そのまま／ふりがな／ひらがな）は、例文の中の問題以外の漢字に適用します。問題の部分には、答えが分かってしまうのでふりがなを付けません。

### 教材データ（`content/`）

- `content/kana/words.json`：ひらがなの絵（絵文字と、その文字で始まる言葉）。
- `content/kanji/grade1.json`：1年の漢字80字です。2〜6年は確認が済んだら学年ごとに追加します。1字ごとに次の内容を持ちます。
  - 音読み・訓読み（送りがなは `.` で区切る。例：`ひと.つ`）
  - 例（熟語・読み・例文・読みのまちがいの選択肢3つ・漢字のまちがいの選択肢3つ）
- **例文の書式**：`{漢字|よみ}` はふりがな付きの漢字、`[[漢字]]` は問題の部分です。問題以外の漢字には、必ずふりがなを付けます。

### 親の確認 → 取り込み

1. 確認用のページを作ります。

   ```bash
   node scripts/make-review.cjs review.html
   ```

   例文・正解・まちがいの選択肢を一覧にしたページができます。
2. 確認が済んだら、JSON の `"reviewed": false` を `true` にしてデプロイします。
3. 未確認のレベルは、本番では選択肢に出ず、出題もされません。K02（カタカナ）は文字表だけで作るので、確認なしで使えます。

### 検証

```bash
npm run content:check
```

`npm test` にも含まれています。次のことを確認します。

- 学年ごとの字数（80／160／200／202／193／191）と、重複がないこと
- 読みの形式（音読みはカタカナ、訓読みはひらがな）と、例文の書式
- 正解がまちがいの選択肢に入っていないこと（選択肢は4つでそれぞれ違う）
- 例文と熟語に、そのレベルまでに習わない漢字を使っていないこと
- 漢字のまちがいの選択肢が、その学年までの漢字であること

## 8. プリント（紙の教材）

親の画面の「プリント」から作ります。毎日の「達成」やお休み券には数えない、おまけの教材です。

| 種類 | 内容 |
|---|---|
| 算数の計算プリント | 子どもの今のレベル（または選んだレベル）の問題を10〜50問。アプリと同じ問題作成プログラムを使う |
| 漢字の書き取りプリント | 例文の □ に漢字を書く（□の上に読みがな）。5〜20問で、1ページ10問ずつ |

- **印刷**：A4 の印刷用ページを、ブラウザの印刷で紙にするか PDF に保存します。問題のページのあとに答えのページ（赤字）が続きます。
- **同じ問題の作り直し**：プリントには「No.」（6けたの番号）が付き、URL にも入ります。同じ URL を開くと同じ問題になります。「ちがう問題で作り直す」で番号が変わります。
- **1ページに収める工夫**：算数は、問題数に合わせて行の高さと文字の大きさを調整します。漢字は書きやすい大きさのマスを保つため、10問をこえたら2ページに分けます。
- **フォント**：答えの漢字は教科書体（Google Fonts の Klee One）で表示します。読み込めないときは明朝体になります。
- **見られる人**：プリントのページも親の画面と同じで、ログインと PIN が必要です。子ども端末からは開けません。
- **まだないもの**：筆順（書き順）、なぞり書き、プリントの採点結果の記録。
