# CLAUDE_CODE_PROMPT.md

あなたは家庭用の子ども向け学習アプリを開発します。仕様はすべて同じリポジトリの `SPEC.md` にあります。最初に `SPEC.md` を全文読んでから作業してください。

## 今回のゴール
`SPEC.md` の **Phase 1（土台＋算数）** を完成させ、Cloudflare にデプロイできる状態にする。

## 技術の前提
- Next.js 15（App Router, TypeScript strict）
- Cloudflare Workers へのデプロイは OpenNext の Cloudflare アダプタ（`@opennextjs/cloudflare`）を使う。最新の推奨手順を公式ドキュメントで確認してから構成すること
- DB は Cloudflare D1。マイグレーションは `wrangler d1 migrations` で管理
- スタイルは Tailwind CSS。その他の依存は必要最小限にし、追加する場合は理由を書く
- テストは Vitest
- モバイルファースト。PWA（manifest とアイコン、ホーム画面追加）に対応
- UI の文言はすべて日本語

## 進め方
1. まず実装計画を短くまとめて提示し、私の確認を待つ（ディレクトリ構成、テーブル定義、画面一覧、実装順）
2. 確認後、次の順で実装する。各ステップの終わりに動作確認の方法を書く
   1. プロジェクト作成、D1 接続、マイグレーション
   2. 親の認証（メール＋パスワード、PIN）
   3. 子ども登録、端末登録コード、子ども端末の長期ログイン
   4. 算数の問題生成エンジン（M01〜M29）とユニットテスト
   5. 学習の流れ（実際に解いていた時間の計測、即採点、間違い直し、当て推量フラグ）
   6. 進級・復習判定とユニットテスト
   7. 日ごとの状態・お休み券・特別休み・月の達成判定・連続日数とユニットテスト
   8. 子どもの画面（ホーム、学習、完了、きろく）
   9. 親の画面（ダッシュボード、子ども詳細、特別休み、設定、月の結果）
   10. PWA 対応とデプロイ手順の README

## 必ず守ること
- **日付・月の判定ロジック（SPEC 5章）は純粋関数として分離し、テストを厚く書く**。最低限次のケースを含める：
  - 28日・30日・31日の月
  - お休み券5枚ちょうどで達成、6日目の未実施で達成ならず
  - 特別休みの日はお休み券を減らさない・対象日数から外れる
  - 特別休みを過去日にさかのぼって設定・取り消ししたときの再計算
  - 日の区切り 3:00 JST（2:59 の学習は前日扱い）
  - 連続日数がお休み券・特別休みで途切れないこと
- 算数の問題生成は、答えをコードで計算し、各レベルで条件（くり上がりの有無、あまりの有無、桁数など）を満たすことをテストで確認する
- 分数の答えは約分して比較する（未約分の入力をどう扱うかはレベルごとに決め、実装計画で提示する）
- 子ども端末からは親用の API・画面に一切アクセスできないようにする（サーバー側で権限チェック）
- パスワードと PIN はハッシュ化して保存。端末トークンもハッシュで保存
- SPEC と違う判断をしたくなったら、実装前に理由を添えて相談すること
