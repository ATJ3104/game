# SPEC.md — 子ども向け毎日学習アプリ（仮称：まいにちドリル）

## 1. 概要

公文式のような「毎日決まった量・細かい段階・即採点・間違い直し」を、スマホで3人の子どもが毎日30分取り組める形で実現する家庭用学習アプリ。
学年ではなく**教科ごとのレベル（段階）**で進み、その子の正答率と解答速度に応じて自動で進級・復習する。
継続の仕組みとして「月のお休みは5日まで」でお小遣いがもらえる日数制度を持つ。

### 利用者
| 区分 | 人数 | 端末 | 備考 |
|---|---|---|---|
| 親 | 1〜2人（夫婦） | 各自のスマホ | 管理・特別休み設定・進捗確認 |
| 子ども | 3人（小1・小5・小6） | 各自のスマホ | 学習のみ。親の画面には入れない |

### 教科
算数・国語・英語（すべて学年ではなくレベルで管理）

---

## 2. 技術構成

- **フロント／サーバー**：Next.js 15（App Router, TypeScript）
- **ホスティング**：Cloudflare（OpenNext の Cloudflare アダプタで Workers にデプロイ）
- **DB**：Cloudflare D1（SQLite）
- **PWA**：ホーム画面に追加してアプリのように使える。モバイルファースト
- **音声**：英語の読み上げはブラウザ標準の Web Speech API（speechSynthesis, en-US）
- **依存は最小限**。UIライブラリは Tailwind CSS 程度に留める
- **テスト**：Vitest（日次・月次判定ロジック、問題生成ロジックは必ずユニットテスト）

---

## 3. 認証・端末

### 親
- メールアドレス＋パスワードでログイン（家族アカウントに親を最大2人まで）
- 親画面に入るときは4桁PINを追加で要求（子どもが親のスマホを触ったとき用）

### 子ども
- 親画面で子どもを登録 → 「端末登録コード」（6桁・10分有効）を発行
- 子どものスマホでコードを入力すると、その端末が子どもとして長期ログイン状態になる（httpOnly Cookie の端末トークン）
- 以後、子どもはアプリを開くだけで学習開始できる。パスワード入力なし
- 親画面から端末の登録解除ができる

## 4. 毎日の学習

### 4.1 今日のメニュー
- 1日の目標は **30分**（初期値：算数10分・国語10分・英語10分）
- 各教科の時間は子どもごとに親が変更できる
- 教科の順番は固定（算数 → 国語 → 英語）。1教科ずつ完了させる
- **3教科すべて完了で、その日は「達成」**

### 4.2 時間の測り方（実際に解いていた時間）
- 計測するのは「問題画面で操作している時間」のみ
- 最後の操作から **60秒** 何もなければタイマー停止（画面に「つづける」ボタンを表示）
- アプリを閉じる・別アプリに切り替えた間はカウントしない
- 教科の目標時間に達したら、今解いている問題を終えてからその教科の「間違い直し」へ

### 4.3 出題と採点
- 1画面1問。答えるとすぐに〇×を表示
- 間違えた問題は教科の最後に**間違い直し**として再出題し、全部正解するまで繰り返す（間違い直しの時間は30分に含める）
- **速すぎる回答**（問題表示から1秒未満など、教科ごとに閾値を設定）は記録上「当て推量」フラグを付け、進級判定に使わない

### 4.4 レベル（段階）の進み方
- 子ども×教科ごとに現在のレベルを持つ
- 進級条件（初期値、設定で調整可能）：
  - そのレベルで直近 **3回** の学習が、正答率 **90%以上** かつ 平均解答時間がレベルの目標時間以内 → 次のレベルへ
- 復習条件：
  - 直近 **2回** 続けて正答率 **70%未満** → 1つ前のレベルの問題を3割混ぜて出題
- 親は親画面からレベルを手動で上げ下げできる
- 初期レベルは親が設定する（Phase 2以降で簡単な実力診断テストを検討）

### 4.5 表示上の配慮
- 子どもごとに「漢字にふりがな（またはひらがな表示）」の設定を持つ（小1向け）
- ボタンは最低48px角。テンキーは画面下部に大きく配置

## 5. お小遣いの日数制度

### 5.1 ルール
- **その月の「やらなかった日」が5日以内なら、今月のお小遣い達成**
- やらなかった日には **お休み券** が自動で1枚使われる。お休み券は **月5枚**
- お休み券の使い方に制限はない（連続で使ってもよい）
- **特別休み**の日は判定の対象外（やらなくてよい日。お休み券も減らない）
- 半額などの中間ラインはなし（達成か未達成のみ）

### 5.2 特別休み
- **親だけ**が親画面から設定できる（子どもからは設定・申請不可）
- 日付（範囲指定可）と理由を登録：「病気」「学校行事」「家族の用事」「その他（メモ）」
- 過去日にさかのぼって設定・取り消しができる（風邪で休んだ翌日に登録するケースを想定）

### 5.3 日ごとの状態
各日は次のいずれかになる：
| 状態 | 意味 |
|---|---|
| 達成 | 3教科すべて完了 |
| 特別休み | 親が設定した日 |
| お休み券 | やらなかった日（その月の1〜5日目の未実施日） |
| 未達成 | やらなかった日（お休み券が尽きた後） |
| 今日 / 未来 | 判定前 |

- 日の区切りは **日本時間 3:00**（夜遅くに取り組んだ分を前日扱いにするため。設定値で変更可能）
- 状態は記録から**都度計算**する（締め処理のバッチは不要。月末確定のみ保存）

### 5.4 月の達成判定
- 未達成の日が1日でも出た時点で、その月は「達成ならず」が確定
- 月が終わったら結果を確定保存し、親画面に「今月の結果」を表示
- 親は「お小遣い支払い済み」をチェックできる
- お小遣いの金額は子どもごとに親が設定（表示用。決済機能は持たない）

### 5.5 連続日数
- 「達成」「特別休み」「お休み券」の日は連続日数が途切れない
- 「未達成」の日で途切れる

## 6. 画面

### 6.1 子ども
1. **ホーム**：今日のメニュー（3教科の進み具合）、「はじめる」ボタン、今月のカレンダー（日ごとの状態）、残りお休み券、連続日数
2. **学習画面**：問題、入力欄（テンキー／選択肢）、残り時間のバー、〇×表示
3. **教科完了・今日の達成画面**：がんばりを讃える演出（シンプルなアニメーションで十分）
4. **きろく**：教科ごとの現在レベル、これまでの達成日数

### 6.2 親
1. **ダッシュボード**：3人の今日の状態（未着手／途中／達成）を一覧
2. **子ども詳細**：月カレンダー、教科ごとのレベル推移、よく間違える問題の種類、1日の学習時間
3. **特別休みの設定**
4. **設定**：子どもの登録・端末登録コード発行・端末解除、教科ごとの時間、お小遣い金額、ふりがな設定、レベル手動調整
5. **月の結果**：達成／達成ならず、支払い済みチェック

## 7. 教材（コンテンツ）

### 7.1 方針
- **算数**：プログラムで問題を自動生成（答えはコードで計算するので必ず正しい）
- **国語・英語**：問題データを JSON でリポジトリに持つ（`content/`）。データは Claude Code の作業中に作成し、親が確認してから取り込む
- アプリ実行中にAIで問題を生成することはしない（誤りとコストを避ける）
- 全データに検証スクリプトを用意（重複、答えが選択肢に含まれるか、読みの形式など）

### 7.2 算数レベル表（初期案）
入力：テンキー（小数点・分数入力欄・あまり入力欄をレベルに応じて表示）

| コード | 内容 |
|---|---|
| M01 | 10までのたし算 |
| M02 | 10までのひき算 |
| M03 | くり上がりのあるたし算（20まで） |
| M04 | くり下がりのあるひき算（20まで） |
| M05 | 2けた±1けた |
| M06 | 2けた±2けた（くり上がり・くり下がりなし） |
| M07 | 2けた±2けた（くり上がり・くり下がりあり） |
| M08 | 3けたのたし算・ひき算 |
| M09 | かけ算九九（2・5・3・4の段） |
| M10 | かけ算九九（6・7・8・9・1の段） |
| M11 | 九九ランダム |
| M12 | わり算（九九の逆、あまりなし） |
| M13 | あまりのあるわり算 |
| M14 | 2けた×1けた |
| M15 | 3けた×1けた |
| M16 | 2けた×2けた |
| M17 | 2けた÷1けた |
| M18 | 3けた÷1けた |
| M19 | ÷2けた |
| M20 | 小数のたし算・ひき算 |
| M21 | 小数×整数、小数÷整数 |
| M22 | 分数のたし算・ひき算（同じ分母） |
| M23 | 約分・通分 |
| M24 | 分数のたし算・ひき算（ちがう分母） |
| M25 | 小数×小数 |
| M26 | 小数÷小数 |
| M27 | 分数×分数 |
| M28 | 分数÷分数 |
| M29 | 計算の順序（四則混合・かっこ） |

各レベルに「目標の平均解答時間」を設定する。

### 7.3 国語レベル表（初期案）
- **K01〜K02**：ひらがな・カタカナの読み（文字を見て読みを選ぶ／読みを聞いて文字を選ぶ）
- **K10以降**：学年別漢字配当表（全1,026字：1年80・2年160・3年200・4年202・5年193・6年191）を約20字ずつに区切ってレベル化
- 出題形式：
  - 漢字の読みを選ぶ（熟語・短い文の中で）
  - 読みに合う漢字を選ぶ（同音異字を選択肢に入れる）
- 書き取りは紙のノートで行い、アプリでは扱わない（将来検討）
- データ：`content/kanji/*.json`（漢字、学年、音読み、訓読み、例の熟語と読み、例文）

### 7.4 英語レベル表（初期案）
- **E01〜E02**：アルファベット（大文字・小文字の対応、音を聞いて文字を選ぶ）
- **E10以降**：小学校で扱う英単語（約600〜700語）をテーマ別に区切ってレベル化（動物、食べ物、色、数、曜日、身の回り…）
- **E50以降**：短いフレーズ（あいさつ、I like 〜、Can you 〜? など）
- 出題形式：
  - 音声を聞いて意味を選ぶ
  - 英単語を見て意味を選ぶ／意味を見て英単語を選ぶ
  - 単語を並べ替えてフレーズを作る
- 低学年向けの絵は**絵文字**で代用（画像素材を持たない）
- データ：`content/english/*.json`（単語、意味、テーマ、絵文字、例文）

## 9. 開発フェーズ

### Phase 1：土台＋算数
- 親アカウント・PIN・子ども登録・端末登録
- 学習の流れ（時間計測、即採点、間違い直し、進級・復習判定）
- 算数の問題生成（M01〜M29）
- 日ごとの状態・お休み券・特別休み・月の達成判定・連続日数
- 子どもホーム／学習画面／親ダッシュボード／特別休み設定
- ※国語・英語が入るまでは、メニューは算数のみ（時間は親が設定）

### Phase 2：国語（ひらがな・カタカナ・漢字）
### Phase 3：英語（アルファベット・単語・フレーズ、読み上げ）
### Phase 4：拡張候補
- 文章題・読解（AIで作成→親確認→取り込み）
- 初期レベルの実力診断テスト
- 未着手時のリマインド通知（Web Push）
- 3人とも達成した日の家族ボーナス演出
